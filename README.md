# UW Shuffle — Making Quest Easier to Use

UW Shuffle is a Chrome extension built by UW students, for UW students.  
Stop struggling with Quest — preview schedules, plan with friends, and check professor ratings directly in the interface.

---

## Features
- Visual schedule preview: Instantly see a clean weekly calendar when testing swaps  
- Professor insights: View UW Flow ratings and reviews directly in the sidebar  
- Quick schedule sharing: Generate shareable links that friends can import with one click  
- Export to calendar: Download as `.ics` for Google, Apple, or any calendar app  

---

## Installation
1. Download or clone this repository  
2. Open `chrome://extensions/` in Chrome  
3. Enable **Developer Mode** (top right)  
4. Click **Load unpacked** and select the project folder  
5. UW Shuffle will appear in your extensions list  

Or install directly from the [Chrome Web Store](https://chrome.google.com/webstore/detail/uw-shuffle/).
